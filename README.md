# Enterprise SQL Case Studies

A collection of PostgreSQL solutions for technical interview assessments from LeetCode, DataLemur, and StrataScratch.

## Structure

| Directory | Source Context | Focus Areas |
| :--- | :--- | :--- |
| `stratascratch/` | Enterprise & FAANG Cases (Meta, Amazon, Uber) | Multi-table CTEs, workforce metrics, ratios |
| `datalemur/` | Tech & Finance Case Studies (Robinhood, Tesla) | Analytical functions, rolling metrics, auditing |
| `leetcode/` | Data Modeling & Relational Logic | Joins, string/date parsing, edge cases |

## Key Concepts

- Window Functions (`DENSE_RANK`, `ROW_NUMBER`, `LEAD`, `LAG`)
- Aggregations (`STRING_AGG`, `HAVING`, multi-column `GROUP BY`)
- Relational Joins (Self-joins, anti-joins, full outer joins)
- Data Cleaning (`COALESCE`, pattern matching, date extractions)

## Environment
PostgreSQL 14+
